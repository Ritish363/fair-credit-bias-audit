# Fair Credit – Algorithmic Bias Audit

**Live Website:** https://fair-credit-bias-audit.vercel.app/

## About the Project

Fair Credit is an AI-based project focused on auditing and mitigating algorithmic bias in digital micro-lending. It aims to identify potential fairness issues in credit approval systems and make lending decisions more transparent.

## Features

- Credit approval analysis and visualizations
- Algorithmic bias and fairness auditing
- Analysis of potential proxy discrimination
- Model performance and fairness trade-offs
- Bias mitigation analysis

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Machine Learning and Fairness Analysis
